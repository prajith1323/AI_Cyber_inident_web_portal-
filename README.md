# AI Cyber Incident Web Portal

A web portal for defense cyber analysts to submit incident reports and receive AI-powered analysis, classification, severity assessment, and response recommendations.

## Features

- Incident report submission form
- Automated attack type classification
- Severity and risk assessment
- Impact prediction
- Immediate response actions
- Long-term preventive measures

## Setup

1. Ensure Python 3.8+ is installed.
2. Create a virtual environment: `python -m venv .venv`
3. Activate the virtual environment: `.venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Run the application: `python main.py`
6. Open http://127.0.0.1:5000/ in your browser.

## Usage

1. Fill out the incident details in the form.
2. Submit to receive analysis in the specified format.
3. Review recommendations and take appropriate actions.

## Security Note

This is a demonstration tool. In production, implement proper authentication, encryption, and secure handling of sensitive incident data.
